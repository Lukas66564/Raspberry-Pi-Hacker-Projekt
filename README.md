# Raspberry-Pi-Hacker-Projekt

Der Versuch, mit einem Raspberry Pi und ein paar anderen Komponenten eine Art Flipper Zero zu bauen.

Mit 13 habe ich zu Weihnachten einen Raspberry Pi bekommen. Ursprünglich hatte ich ihn mir gewünscht, weil ich auf YouTube ein Tutorial gesehen hatte, in dem gezeigt wurde, wie man eine eigene Cloud mit Nextcloud baut. Doch als ich ihn bekam, hatte ich eine andere Idee. Mein Freund hatte einen Flipper Zero und so etwas wollte ich auch haben.

Also habe ich mir auf Amazon einen 7-Zoll-Touchscreen geholt. Mit einem Paket aus dem Keller, einer alten Powerbank, dem Touchscreen und dem Raspberry Pi habe ich dann den ersten Prototypen gebaut. Auf dem Raspberry Pi habe ich anschließend Kali Linux installiert.

![Bild](picture.jpg)

Allerdings habe ich gemerkt, dass der Raspberry Pi allein nicht so viele Möglichkeiten bietet. Deswegen habe ich den Alfa AWUS036ACS eingebaut. Zusätzlich kam noch ein USB-Hub hinzu.

Dieser WLAN-Stick unterstützte deutlich mehr Funktionen als der integrierte WLAN-Chip des Raspberry Pi. Außerdem hatte er eine höhere Sende- und Empfangsleistung. Zusätzlich unterstützte er Funktionen wie den Monitor Mode, der unter anderem für die Analyse von WLAN-Paketen und bestimmte Tests zur Paketinjektion verwendet werden kann.
